# Coffee'station Plan Summary

## Bottom line

The purpose is to let customers browse the cafe's menu, order items, and reserve a table without visiting in person — while also giving admins a way to manage the menu (add, update, remove items) through the same application.

## Key points
 
- **Menu & Ordering:** Browse items by category (Coffee, Tea, Desserts, Breakfast, Combos), add to cart, adjust quantity, and see the total.
- **Booking:** Book a table with name, date, number of guests, and preferred time.
- **Site Pages:** Home, About, and Contact pages present the cafe's brand and info.
- **Tech Stack:** React + Vite + TypeScript, Tailwind CSS, Zustand for state, React Router, Framer Motion for animations.
- **Fully Responsive:** Works across mobile, tablet, and desktop.
